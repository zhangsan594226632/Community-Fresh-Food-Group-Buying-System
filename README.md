# Community-Fresh-Food-Group-Buying-System
【万字文档+源码】 基于SpringBoot+Vue社区生鲜团购系统-可用于毕设-课程设计-练手学习-学习资料分享-本项目开发一套社区生鲜团购平台，采用前后端分离架构（Vue+SpringBoot），实现居民在线购买、团长自提管理、管理员后台维护的一体化解决方案。系统包含三大核心模块：前台面向居民提供商品浏览、购物车、订单管理功能；团长端支持自提点申请、接货/取货登记；后台管理系统实现商品、订单、用户等全数据管理。数据库设计涵盖12张核心表，支持生鲜商品全生命周期管理。平台通过线上流程优化，解决传统生鲜采购价格不透明、配送不便等痛点，构建高效的社区团购生态。
