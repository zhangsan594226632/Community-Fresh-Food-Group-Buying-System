## 一、项目概述

### 1\.1 项目背景

随着社区经济快速发展，社区生鲜团购模式成为居民日常采购果蔬生鲜的主流方式。传统生鲜购买渠道存在采购耗时、价格不透明、配送不便等问题。为打通生鲜供货商、社区团长、社区居民三者之间交易链路，搭建一套线上社区生鲜团购平台。
居民在线浏览生鲜商品、加入购物车、下单购买；社区团长负责自提点货物接收、通知居民取货；平台管理员统一管理商品、订单、团长、资讯等全部数据，实现生鲜团购业务线上规范化管理。

### 1\.2 项目目标

1. 面向居民用户：提供生鲜商品浏览、资讯查看、购物车、在线下单、订单管理整套线上购物流程；

2. 面向社区团长：注册账号、管理自提点、接收团购货物、登记居民取货信息；

3. 面向系统管理员：统一维护商品、商品分类、轮播图、资讯、用户、团长、订单、提货信息等后台数据；

4. 实现前后端分离架构，界面简洁友好，生鲜行业视觉风格，分页查询、条件检索、增删改查、图片上传等基础功能全覆盖。

### 1\.3 技术架构

#### 后端技术栈

- 核心框架：**SpringBoot 2\.x**

- 持久层框架：MyBatis / MyBatis\-Plus

- 数据库：MySQL 8\.0

- 工具：Lombok、Hutool、FileUpload 文件上传、Jackson 序列化

- 服务：Tomcat 内置容器

#### 前端技术栈

- 核心框架：**Vue2 / Vue3 \+ Vue CLI**

- UI 组件库：Element UI / Element Plus

- 路由：Vue Router

- HTTP 请求：Axios

- 页面轮播：Swiper

- 页面样式：CSS、Less

#### 架构模式

**前后端分离架构**
前端独立部署，负责页面渲染、交互；后端提供 RESTful API 接口，负责业务逻辑、数据持久化；前后端通过 JSON 格式完成数据交互。

### 1\.4 用户角色划分

系统一共分为三大角色，权限相互隔离：

1. **普通居民用户（前台用户）**：访问网站首页、商品列表、资讯、购物车、下单、个人订单管理；

2. **社区团长**：账号注册、自提点申请、查看接货信息、录入取货信息；

3. **系统管理员（后台管理）**：最高权限，管理系统全部基础数据、商品、订单、用户、团长、资讯、轮播图。

## 二、系统功能需求分析

### 2\.1 前台居民用户模块（网站前端页面）

参照截图页面：首页轮播、商品信息页、购物车、订单页面、登录注册页面

1. **首页模块**

    - 顶部导航栏：首页、商品信息、商品资讯、购物车；

    - 轮播图展示生鲜宣传图片；

    - 商品推荐区域，展示生鲜商品缩略信息；

2. **商品信息模块**

    - 分页展示全部生鲜商品；展示商品图片、商品名称、保质期、售价；

    - 支持浏览商品详情，加入购物车；

3. **商品资讯模块**

    - 展示生鲜科普、平台公告、活动资讯；

4. **购物车模块**

    - 管理已加入购物车商品，修改数量、删除商品、结算下单；

5. **订单管理模块**

    - 创建订单，支持查看订单；订单状态区分：未支付、已支付、已完成、已退款、已取消；

6. **登录 \& 注册**

    - 用户账号登录；新用户注册账号。

### 2\.2 社区团长模块

1. 团长注册：填写账号、密码、姓名、头像、联系电话、自提点名称完成注册；

2. 自提点申请；

3. **接货信息管理**：查看居民团购订单，接收平台下发生鲜货物；

4. **取货信息管理**：居民到店取货后，登记取货记录。

### 2\.3 管理员后台模块（后台管理系统）

参照后台截图左侧菜单栏，功能清单：

1. **自提点申请管理**
查看团长提交的自提点申请，审核处理；

2. **用户管理**
管理平台居民账号信息，查询、编辑、删除用户；

3. **团长管理**
维护全部社区团长信息，查看团长自提点信息；

4. **商品信息管理**

    - 商品信息：生鲜商品新增、修改、删除、分页查询、图片上传；

    - 商品分类：搭建生鲜分类（蔬菜、水果等）；

5. **自提商品管理**

    - 接货信息：查看所有团购接单记录，支持条件检索、查看详情；

    - 取货信息：管理居民取货登记数据；

6. **商品资讯管理**
资讯公告新增、编辑、删除、标题搜索；支持资讯配图上传；

7. **管理员管理**
维护后台管理员账号；

8. **轮播图管理**
维护首页前台轮播图片，新增、修改、删除轮播项；

9. **商品订单管理**
查看平台全部用户订单；按照订单状态筛选（全部 / 未支付 / 已支付 / 已完成 / 已退款 / 已取消）；支持订单编号检索。

## 四、系统模块详细设计

### 4\.1 用户登录注册模块

1. **前台居民登录**：输入账号密码校验，登录成功跳转首页；未登录无法加入购物车、下单；

2. **团长注册**：填写表单信息提交，等待管理员审核；

3. **后台管理员登录**：选择用户类型【管理员】，账号密码登录进入后台管理主页；

4. 密码加密存储，支持记住密码、退出登录、修改密码功能。

### 4\.2 前台商品浏览模块

1. 首页加载轮播图、推荐商品；

2. 商品信息页面分页加载所有生鲜商品，展示图片、名称、保质期、售价；

3. 用户点击商品查看详情，加入购物车；

### 4\.3 购物车与订单模块

1. 登录用户可以将商品加入购物车；

2. 购物车勾选商品进行结算，生成订单；

3. 订单状态流转：未支付 → 已支付 → 已完成；支持退款、取消操作；

4. 用户前台可根据状态筛选订单；管理员后台查看全站所有订单。

### 4\.4 团长自提业务流程

1. 团长注册 → 提交自提点申请；

2. 居民下单生鲜商品，订单流转至对应自提点团长；

3. 团长在【接货信息】查看需要接收的生鲜货物；

4. 居民前往自提点提货，团长登记【取货信息】，完成整个团购闭环。

### 4\.5 后台基础数据管理

1. **轮播图管理**：管理员上传图片维护前台首页轮播；支持新增、修改、删除；

2. **资讯管理**：发布生鲜公告、行业资讯，前台用户可以浏览；支持标题搜索；

3. **商品分类与商品管理**：先建立分类，再录入生鲜商品，上传商品图片，维护保质期、价格；

4. **人员管理**：统一管理居民用户、社区团长、后台管理员账号；

## 五、系统运行流程

1. 居民访问前台首页，浏览生鲜商品与资讯；

2. 未登录先完成账号注册、登录；

3. 将心仪生鲜加入购物车，结算生成订单；

4. 平台将订单分配至对应社区自提点团长；

5. 团长接收货物，等待居民上门自取；

6. 居民到达自提点取货，团长登记取货信息；

7. 管理员在后台实时监控所有商品、订单、团长、用户数据，维护平台基础信息。
